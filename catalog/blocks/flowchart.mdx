## 安装

<CodeGroup>

```bash Terminal
npx hyperframes add flowchart
```

</CodeGroup>

## 细节

| 财产 | 价值 |
| --- | --- |
| 类型 | 堵塞 |
| 方面 | 1920×1080 |
| 期间 | 12秒 |

## 文件

| 文件 | 目标 | 类型 |
| --- | --- | --- |

## 用法

安装后，将该块添加到您的主机组合中：

```html
<div data-composition-id="flowchart" data-composition-src="compositions/flowchart.html" data-start="0" data-duration="12" data-track-index="1" data-width="1920" data-height="1080"></div>
```
