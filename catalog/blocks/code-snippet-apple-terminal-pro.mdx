## 特征

- 忠实再现 macOS Terminal.app Pro 配置文件 — 黑色背景、#BBBBBB 灰色文本、#88FF67 石灰光标
- 带有交通灯按钮和居中标题栏的 macOS 窗口镀铬
- 每个字符的 GSAP 键入动画 — 命令逐个字符地键入
- 命令执行后输出行按顺序显示
- 光标最后闪烁三下然后保持稳定
- 独立的 HTML — 没有外部资产，只有 GSAP CDN
