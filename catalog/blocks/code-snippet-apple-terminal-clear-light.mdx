# 苹果终端透明灯

内置 Clear Light 配置文件中的 macOS Terminal.app 窗口 — 半透明白色背景，带有黑色文本和灰色光标。每个字符的打字动画与输出显示。

## 特征

- 忠实再现 macOS Terminal.app Clear Light 配置文件 — 半透明白色背景和黑色文本
- 带有交通灯按钮和居中标题栏的 macOS 窗口镀铬
- 每个字符的 GSAP 键入动画 — 命令逐个字符地键入
- 命令执行后输出行按顺序显示
- 光标最后闪烁三下然后保持稳定
- 独立的 HTML — 没有外部资产，只有 GSAP CDN
