以下团队附带了 HyperFrames。如果您的组织在生产、评估或业余项目中使用 HyperFrames，我们很乐意添加您。

## 如何添加您的组织

打开一个拉取请求，将您的团队添加到存储库根目录的 [`ADOPTERS.md`](https://github.com/heygen-com/hyperframes/blob/main/ADOPTERS.md)。该格式故意是轻量级的：

- **组织** — 您的公司或项目名称，链接到您的网站。
- **联系方式** — GitHub 句柄，以便其他采用者可以联系。
- **如何使用 HyperFrames** — 一句话介绍用例。
- **徽标** _（可选）_ — 要在此页面上显示的方形徽标或图标。如果您跳过此步骤，您的条目仍会显示在下表中。

如果您不想公开列出，我们仍然希望了解您的使用情况 - 在 [我们的 Discord](https://discord.gg/EbK98HBPdk) 中留言。
