# 苹果终端纯色

内置纯色配置文件中的 macOS Terminal.app 窗口 — 生动的深紫色 `#4C0099` 背景和白色文本。引人注目且充满活力，带有每个字符的打字动画。

## 特征

- 忠实再现 macOS Terminal.app 纯色配置文件 — #4C0099 深紫色背景与白色文本
- 带有交通灯按钮和居中标题栏的 macOS 窗口镀铬
- 每个字符的 GSAP 键入动画 — 命令逐个字符地键入
- 命令执行后输出行按顺序显示
- 光标最后闪烁三下然后保持稳定
- 独立的 HTML — 没有外部资产，只有 GSAP CDN
