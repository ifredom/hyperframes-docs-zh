# 光+

VS Code 工作台，在 Light+ 主题中具有每个字符的打字动画。完整的编辑器镶边，带有活动栏、侧边栏、选项卡、终端和状态栏。

## 安装

<CodeGroup>

```bash Terminal
npx hyperframes add code-snippet-light-plus
```

</CodeGroup>

一次安装所有代码片段主题：

```bash Terminal
npx hyperframes add code
```

## 用法

安装后，将该块添加到您的主机组合中：

```html
<div
  data-composition-id="code-snippet-light-plus"
  data-composition-src="compositions/code-snippet-light-plus.html"
  data-start="0"
  data-duration="11"
  data-track-index="1"
  data-width="1920"
  data-height="1080"
></div>
```

## 特征

- 完整的 VS Code 工作台娱乐 — 活动栏、侧边栏、资源管理器树、编辑器选项卡、面包屑、终端面板、状态栏
- 每个字符的打字动画，具有光标跟踪和活动行突出显示
- 颜色源自官方 `microsoft/vscode` 内置主题 JSON
- 打字序列结束时的 3D 透视倾斜
- 带模拟测试输出的终端面板
