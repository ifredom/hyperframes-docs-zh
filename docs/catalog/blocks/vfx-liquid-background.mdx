# 液体背景

在细分平面上进行顶点位移的有机液体模拟。 HTML 内容漂浮在带有实时波浪动力学的波纹流体表面上。

`html-in-canvas` `liquid` `webgl` `displacement` `background`

<Warning>
**需要 Chrome 标志。** 启用 `chrome://flags/#canvas-draw-element` 进行实时预览。通过 CLI 渲染会自动启用该标志。 [了解更多](/guides/html-in-canvas)。
</Warning>

## 安装

<CodeGroup>

```bash Terminal
npx hyperframes add vfx-liquid-background
```

</CodeGroup>

## 细节

| 财产 | 价值 |
| --- | --- |
| 类型 | 堵塞 |
| 方面 | 1920×1080 |
| 期间 | 12秒 |

## 文件

| 文件 | 目标 | 类型 |
| --- | --- | --- |
| `vfx-liquid-background.html` | `compositions/vfx-liquid-background.html` | 超框架:组合 |

## 用法

安装后，将该块添加到您的主机组合中：

```html
<div data-composition-id="vfx-liquid-background" data-composition-src="compositions/vfx-liquid-background.html" data-start="0" data-duration="12" data-track-index="1" data-width="1920" data-height="1080"></div>
```
